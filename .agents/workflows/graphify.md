# Workflow: graphify
**Command:** /graphify
**Description:** Turn any folder of files into a navigable knowledge graph

## Steps
If a Graphify skill or command is installed locally, it may supplement `rg` and source inspection. If it is unavailable, continue from canonical docs, `rg`, and source inspection.

If no path argument is given, use `.` (current directory).

Graphify output is generated supporting context only. The canonical policy is [Documentation Protocol §11](../../docs/00.agent-governance/rules/documentation-protocol.md); derived projects may regenerate supporting context after project intake.
